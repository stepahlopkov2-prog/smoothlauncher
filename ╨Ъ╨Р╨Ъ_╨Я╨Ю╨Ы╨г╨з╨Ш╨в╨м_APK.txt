║   КАК ПОЛУЧИТЬ APK БЕЗ ANDROID STUDIO           ║
║   (через GitHub — бесплатно, 5 минут)            ║
╚══════════════════════════════════════════════════╝

ШАГ 1 — Создай аккаунт на GitHub
  Зайди на https://github.com и зарегистрируйся

ШАГ 2 — Создай новый репозиторий
  • Нажми кнопку "+" → "New repository"
  • Название: SmoothLauncher
  • Нажми "Create repository"

ШАГ 3 — Загрузи файлы проекта
  • На странице репозитория нажми "uploading an existing file"
  • Перетащи ВСЕ файлы из папки SmoothLauncher в браузер
  • ВАЖНО: загружать именно содержимое папки, не саму папку!
  • Нажми "Commit changes"

ШАГ 4 — Подожди 3-5 минут
  • GitHub автоматически начнёт сборку APK
  • Перейди во вкладку "Actions" в репозитории
  • Увидишь зелёную галочку — сборка готова!

ШАГ 5 — Скачай APK
  • Нажми на "Build APK" в списке Actions
  • Листай вниз до раздела "Artifacts"
  • Скачай "SmoothLauncher-APK"
  • Внутри архива будет файл app-debug.apk

ШАГ 6 — Установи на телефон
  • Перенеси app-debug.apk на телефон
  • Открой файл на телефоне
  • Разреши установку из неизвестных источников
  • Установи!
  • При нажатии HOME выбери SmoothLauncher → "Всегда"
