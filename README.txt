 КАК СОБРАТЬ И УСТАНОВИТЬ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

 Вариант 1 — Через Android Studio (рекомендуется):
  1. Скачайте Android Studio: https://developer.android.com/studio
  2. File → Open → выберите папку SmoothLauncher
  3. Дождитесь синхронизации Gradle
  4. Build → Build APK(s)
  5. APK будет в: app/build/outputs/apk/debug/
  6. Перенесите APK на телефон и установите

 Вариант 2 — Через bat-скрипты (нужен Gradle):
  1. Убедитесь что установлен JDK 17+
  2. Запустите build.bat — соберёт APK в папку release/
  3. Подключите телефон по USB, включите USB-отладку
  4. Запустите install.bat — установит через ADB
